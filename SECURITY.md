# Security Policy

Sub Invaders is a browser-based space shooter game. See [LICENSE](LICENSE) for the full
license text (MIT).

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.** Use GitHub Private Vulnerability
Reporting (PVR) instead — it keeps the report confidential until a fix is ready.

To report:

1. Go to the **Security** tab of this repository and click **"Report a vulnerability"**.
2. Fill in a clear description, steps to reproduce, and (if known) a suggested mitigation.
3. Submit. Only repository maintainers can see the report.

Reference: [Privately reporting a security vulnerability][pvr-docs]

[pvr-docs]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability

There is **no email contact** for security reports — PVR is the only supported channel.

## Response SLA

We will acknowledge receipt on a **best-effort basis within 7 days**. Coordinated disclosure
is preferred; we will agree a public disclosure date with you before any advisory is
published.

## Supported versions

Only the `main` branch receives security fixes.

| Branch / version | Supported |
|------------------|-----------|
| `main`           | ✅         |
| All others       | ❌         |

## Acknowledgements

Reporters will be credited in the published advisory unless anonymity is requested.
